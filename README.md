# Projeto QA — SwagLabs Shopping

Projeto de estudo para praticar testes manuais funcionais, com base no material do curso DIO **“O dia a dia de um QA: A prática de testes manuais funcionais”**.

## Contexto
O material de referência apresenta uma loja virtual (SwagLabs Shopping), Scrum, JIRA para gerenciamento e Confluence para documentação. Os artefatos deste repositório são propostas de estudo e devem ser validados/adaptados ao comportamento real do ambiente.

## Entregáveis
- `docs/projeto-qa-swaglabs.pdf`: documento consolidado com fluxo de trabalho, ciclo de vida de bugs, duas User Stories, mind map textual, plano de testes, dois casos step-by-step, dois casos BDD e ciclo de testes.
- `docs/fluxo-trabalho-e-ciclo-bug.md`
- `docs/user-stories.md`
- `docs/plano-de-testes.md`
- `docs/casos-de-teste.md`
- `docs/mind-map-us02.txt`
- `evidencias/`: adicionar capturas reais após executar os testes.

## Antes de entregar
1. Preencha seu nome e a data no PDF.
2. Revise os critérios de aceite no site real do projeto.
3. Execute os testes e atualize os resultados. Não marque testes como aprovados sem executá-los.
4. Adicione evidências reais, quando disponíveis.

## Enviar para GitHub
```bash
git init
git add .
git commit -m "docs: adiciona projeto de QA SwagLabs"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
git push -u origin main
```
Substitua a URL pelo endereço do seu repositório. Se já houver um repositório Git configurado, não execute `git remote add origin` novamente.
